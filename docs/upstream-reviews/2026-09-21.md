## Security, privacy, and product impact

- The app still executes only the vendored collector file; no npm package,
  mutable tag, dependency, parser, or collector source changed.
- Local snapshot and optional sync now share deadlock-safe process mechanics,
  but retain separate child environments. The local child cannot receive
  `VIBE_USAGE_API_KEY`; the sync child receives it only after opt-in.
- Process stdout/stderr live only in a `0700` temporary directory with `0600`
  files and are removed after completion. Debug logging records byte counts,
  not response or process-output bodies.
- No network destination, settings mutation, persistence format, workflow,
  updater, signing identity, remote-sync default, leaderboard default, project
  upload default, session upload default, or credential-probe default changed.
- Public leaderboard visibility is still applied and read back before upload;
  failure still cancels sync.
